# Innsmouth Street V2 Art

This folder contains scene-facing adaptations for the canonical `InnsmouthStreet` V2. Original third-party files remain under `Assets/ThirdPartyRaw/Ansimuz/` and are not edited.

## Locked usage

- `GothicvaniaTown`: primary street frontage, houses, roof/wall/window tiles, ground pieces, lamps, signs, crates, barrels, and the Tavern language.
- `WarpedOceanView`: distant night ocean layers, clouds, remote silhouettes, and harbor atmosphere only.
- Legacy Collection: not used.
- SeaHook BASIC, bar/cafe packs, Magic Cliffs, and all other packs: prohibited.
